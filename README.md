# Lotus Chinese Restaurant · Дижитал меню

Хятад ресторанд зориулсан гар утсанд түлхүү тохируулсан, премиум түвшний цахим меню.

## Боломжууд

- Нүүр хэсэг: рестораны нэр, танилцуулга, "Меню үзэх" товч, QR кодын хэсэг
- 7 ангилал: Хятад хоол, Гоймон, Будаатай хоол, Банш, Шөл, Амттан, Ундаа
- Бодит хайлт (нэр, орц, хятад болон англи нэрээр; ү/у, ө/о ялгаагүй олно)
- Ангиллаар шүүх, "Онцлох хоол" хэсэг
- Хоолны дэлгэрэнгүй цонх: зураг, нэр, үнэ, тайлбар, тоо ширхэг, "Захиалгад нэмэх"
- Захиалгын сагс: тоо өөрчлөх, ширээний дугаар, нэмэлт хүсэлт, SMS эсвэл утсаар илгээх, хуулах, хуваалцах. Хөтөч дээр хадгалагдана.
- Сайтын хаягаар автоматаар үүсдэг QR код, PNG болгон татах
- Доод навигаци, 48px дээш товчлуурууд: нэг гараар ашиглахад тохиромжтой
- Утасны "буцах" товч нээлттэй цонхыг хаана, `#dish=peking-duck` гэх мэт шууд холбоос ажиллана

## Меню засах

Бүх өгөгдөл **`data/menu.js`** ганц файлд байна:

- `restaurant`: нэр, танилцуулга, хаяг, цагийн хуваарь, утас
- `categories`: ангиллын жагсаалт ба дараалал
- `items`: хоол бүрийн нэр, үнэ, ангилал, тайлбар, зураг, `featured`

Шинэ хоол нэмэхдээ байгаа нэг объектыг хуулж, `id`, `name`, `price`, `category`, `description`, `image`-ийг өөрчилнө.

### Зураг солих

`image` талбарт гурван хэлбэрийн аль нэгийг бичнэ:

```js
image: "commons:Xiaolongbao.jpg"          // Wikimedia Commons файл
image: "images/source/xiaolongbao.jpg"    // Репо дотор хадгалсан өөрийн зураг
image: "https://example.com/photo.jpg"    // Шууд холбоос
```

`npm run build` нь бүх зургийг 960×720 (4:3) хэмжээтэй WebP болгож, ухаалгаар тайрч `dist/images/` руу хадгална. Жижиг 480×360 хувилбар ч мөн үүснэ. Зураг татаж чадаагүй тохиолдолд сайт эх холбоосыг ашиглана.

## Ажиллуулах

```bash
npm install
npm run check   # текстэнд зураас байгаа эсэх, id, үнэ, ангиллыг шалгана
npm run dev     # build хийгээд http://localhost:4173 дээр нээнэ
```

## Deploy (Vercel)

`vercel.json` бэлэн. Vercel дээр репог импортлоход тохиргоо автоматаар уншигдана:
build команд `npm run check && npm run build`, гаралтын хавтас `dist`.

## Зургийн лиценз

Хоолны зургууд Wikimedia Commons дээрх нээлттэй лицензтэй бүтээлүүд. Зохиогч, лицензийг `data/menu.js` доторх `credit` талбар болон сайтын "Зургийн эх сурвалж" хэсэгт харуулсан.
